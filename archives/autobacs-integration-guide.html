AUTOBACS · GUIDE D'INTÉGRATION
INTÉGRATION · NEXT.JS 15

Comment intégrer
les 17 animations.

Composant React avec random sans répétition parmi les 17 animations validées. 4 fichiers à copier dans ton projet, et c'est prêt. Compatible Next.js 15 / React 19 / TypeScript / CSS Modules.

1

Crée le dossier du composant

Dans ton projet, crée la structure suivante. Tu peux la mettre où tu veux selon ton organisation (par exemple src/components/ ou app/components/) :

src/components/
  └── AutobacsLoader/
      ├── AutobacsLoader.tsxle composant principal
      ├── AutobacsLoader.module.cssles 17 animations CSS
      ├── animations.tsconfiguration typée
      └── index.tsexports publics
2

Copie les 4 fichiers

Les 4 fichiers sont dans le même dossier de téléchargement que cette page. Tu peux soit les télécharger directement, soit cliquer sur "Copier" pour avoir le contenu dans ton presse-papier.

AutobacsLoader.tsx
Composant React principal avec random sans répétition, useState lazy init et SVG embarqué.
9.3 KB 220 lignes
AutobacsLoader.module.css
Toutes les règles CSS pour les 17 animations + layout commun + reduced-motion.
49 KB 1288 lignes
animations.ts
Configuration typée des 17 animations avec catégories, durées et helpers.
3.4 KB 103 lignes
index.ts
Exports publics pour faciliter les imports depuis ton app.
0.3 KB 15 lignes
Bonne pratique : Garder le SVG du logo embarqué dans AutobacsLoader.tsx évite un fetch HTTP supplémentaire. Si tu préfères externaliser, tu peux remplacer le composant AutobacsLogo par <Image src="/logo.svg" />.
3

Utilise-le dans ton app

Une fois les fichiers en place, importe et utilise le composant. Il choisit automatiquement une animation au hasard parmi les 17 (sans répéter la précédente).

Usage le plus simple
RANDOM PAR DÉFAUT 
import { AutobacsLoader } from '@/components/AutobacsLoader';

export default function VehicleSearchPage() {
  const { data, isLoading } = useQuery({ ... });

  if (isLoading) {
    return (
      <AutobacsLoader
        title="Identification du véhicule"
        subtitle="Recherche dans la base immatriculation…"
      />
    );
  }
  return <VehicleDetails data={data} />;
}
Avec Suspense (Next.js)
REACT 19 
import { Suspense } from 'react';
import { AutobacsLoader } from '@/components/AutobacsLoader';

export default function Page() {
  return (
    <Suspense fallback={<AutobacsLoader />}>
      <VehicleDetails />
    </Suspense>
  );
}
Forcer une animation spécifique
CAS PARTICULIERS 
// Ex : pour le splash de démarrage tu veux toujours Aurora Wave
<AutobacsLoader
  force="aurora"
  size="lg"
  title="Chargement de l'application"
/>
Exclure certaines anims du pool
CONFIGURATION 
// Garder seulement les anims les plus rapides pour les fetch courts
<AutobacsLoader
  exclude={['lantern', 'incense', 'watercolor', 'fireflies']}
  title="Recherche en cours"
/>
Random uniquement dans une catégorie
USAGE AVANCÉ 
import { AutobacsLoader, getAnimationsByCategory } from '@/components/AutobacsLoader';

// Splash long et apaisant : que des anims poétiques
const poolPoetic = getAnimationsByCategory('poetic').map(a => a.id);

<AutobacsLoader
  pool={poolPoetic}
  size="lg"
  title="Synchronisation longue"
  subtitle="Cela peut prendre quelques minutes…"
/>

Référence des props

Prop Type Description
force AnimationId? Force une animation spécifique au lieu d'un random
exclude AnimationId[]? Anims à retirer du pool de random
pool AnimationId[]? Pool d'anims spécifique (défaut : DEFAULT_POOL = 16 anims sans Live Pulse)
size 'sm' | 'md' | 'lg' | 'xl' Taille du logo (80 / 160 / 240 / 320 px). Défaut : 'md'
title string? Titre affiché sous le logo
subtitle string? Sous-titre en plus petit
fullHeight boolean? Le loader prend min-height: 240px (défaut: true)
className string? Classe CSS supplémentaire
5

Notes importantes

Random sans répétition

Une variable globale lastAnimId garde en mémoire la dernière anim affichée. Au prochain montage du composant (peu importe où dans l'app), elle sera évitée. Ça garantit que tu ne vois jamais 2 fois la même anim de suite.

Live Pulse exclu par défaut

L'animation live (Live Pulse) est une boucle infinie qui ne signale pas de fin de chargement. Elle est exclue du DEFAULT_POOL. Si tu veux l'inclure quand même, passe explicitement pool={[...DEFAULT_POOL, 'live']}.

Accessibilité

Le composant a role="status", aria-live="polite" et aria-label. Il respecte aussi prefers-reduced-motion : les animations sont désactivées pour les utilisateurs qui préfèrent moins de mouvement.

Mode dark

Le composant détecte automatiquement prefers-color-scheme: dark. Si ton app a son propre système de thème, tu peux passer une className et override les variables CSS dans ton thème.

Performance

Le CSS module pèse 49 KB (≈ 12 KB gzip). Toutes les animations sont CSS pur, aucune dépendance JavaScript ajoutée. Le rendu est instantané, pas de FOUC.
